# Security Policy

## Supported Versions
Sentinel V3 is a **Proof of Concept (PoC)** and educational demo. It is not intended for deployment in production environments. 
There are no officially supported, actively patched releases.

## Reporting a Vulnerability
Because this is a demo repository, please do not file CVEs or security advisories for vulnerabilities found in the simulation scripts or dashboard logic, as they are intentionally vulnerable for demonstration purposes.

If you find a critical issue that affects the host system running the demo, please open a standard GitHub Issue or reach out via LinkedIn.
